V2.21.1 DELTA INSTALL
=====================

Prerequisite: V2.21 installed.

1. Extract this ZIP over the repository root.
2. Run:

   python3 -m automation.offline_v2211_selftest

3. Start Skjutbana normally. Camera and projector must be active and the
   projector output must be visible to the camera.

4. In a second terminal, from the repository root, run the first controlled
   capture:

   python3 -m automation.v221_collect_fullframe white --shots 30 --seed 22101

   The collector starts the automation scene, calibrates, starts F2, freezes
   online learning for the capture, and naturally completes after 30 rounds.

5. Then run:

   python3 -m automation.physical_pack_v221_inspect \
     --root content/ai/candidate_shadow_v216

   python3 -m automation.direct_proposal_v221_benchmark \
     --root content/ai/candidate_shadow_v216

Do not run another synthetic-only V2.18 training cycle before evaluating this
full-frame direct-proposal result.
