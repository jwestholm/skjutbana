# Asset provenance

All shipped meshes, room geometry, part masks and animations are original procedural
project assets generated by automation/assets/render_light_room_parts.py.
No Kenney/Poly Haven/Quaternius model or copyrighted sample is included.
No external accounts, downloads or live Blender scene were used.
Generated assets only: CC0-1.0; see LICENSE.txt. Existing project source code is not relicensed.

Free external alternatives (not included), checked 2026-11-22:
- Kenney Furniture Kit: https://kenney.nl/assets/furniture-kit — CC0.
- Poly Haven Jug 01, Kuutti Siitonen: https://polyhaven.com/a/jug_01 — CC0;
  https://polyhaven.com/license .
- Quaternius Ultimate Furniture: https://quaternius.com/packs/ultimatefurniture.html — CC0.
- Cell Fracture: https://extensions.blender.org/add-ons/cell-fracture/ — GPL-3.0-or-later
  for the tool, not a model licence. Not installed or copied into the game.

Current shards use manually authored functional parts and mesh sectors.
The manifest lists hashes for rendered files and exact source recipes.
