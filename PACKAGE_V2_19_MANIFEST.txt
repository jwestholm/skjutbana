Key semantics:
- seed creates a deterministic full BEFORE/AFTER perception world,
- media source/family stays inside one train/validation/holdout split,
- external media provenance/license fields are retained,
- cross-split exact/near media duplicates are audited,
- actual old holes and known_holes are separate concepts,
- hole-in-hole remains valid,
- camera-observed synt_* patches are reused as compact hole appearances by default,
- real hole_* patches remain outside generated training by default,
- dynamic projector/media content can change while physical holes stay fixed,
- current live V1/V2 detector is reused through the existing hardware-free adapter,
- generated candidate packs reuse the V2.16 schema and are consumable by V2.17/V2.18,
- generated/media data never counts as physical acceptance data.
